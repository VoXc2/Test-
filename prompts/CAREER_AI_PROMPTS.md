# Career AI Prompts

## Tailor CV to job

Paste the job description and ask:

Rewrite my CV for this role using only verified information from CV_DATA.yaml. Do not invent employers, education, dates, or metrics. Keep it ATS-friendly. Return: headline, summary, skills, project bullets, and missing proof list.

## Build project bullets

Turn this project into CV bullets using action + method + result. If no metric is provided, write the bullet without a number and list what evidence is missing.

## Interview prep

Create 10 interview questions for this role. Answer using STAR format based only on my verified project notes.

## LinkedIn post

Write a practical LinkedIn post from my real project update. Avoid generic AI content. Make it sound like direct personal learning.

## Opportunity scoring

Score this role from 1 to 5 on role fit, learning value, salary potential, brand value, practicality, and portfolio fit. Explain the decision.
